# book_recommendation_nearest_neighbor

Book recommender built with scikit-learn's `NearestNeighbors` (K-nearest-neighbours on a
user–book ratings matrix).

This is the "Book Recommendation Engine using KNN" challenge from freeCodeCamp's
[Machine Learning with Python](https://www.freecodecamp.org/learn/machine-learning-with-python/)
certification. The notebook is meant to be opened in Google Colab.

## Data provenance
The Book-Crossings dataset is downloaded at runtime from freeCodeCamp's public CDN:

```
https://cdn.freecodecamp.org/project-data/books/book-crossings.zip
```

It originates from the public [Book-Crossing dataset](http://www2.informatik.uni-freiburg.de/~cziegler/BX/)
(Cai-Nicolas Ziegler, 2004), in which users are identified only by an anonymised numeric ID.
No data is committed to this repository, and nothing here comes from any employer.
